Corte Prime

Site comercial / Landing Page

HTMLCSSJavaScript

Landing page demonstrativa criada para apresentar uma solução de site profissional para negócios locais. O projeto inclui hero com chamada direta para o WhatsApp, catálogo de serviços com preços, seção sobre com diferenciais, galeria de trabalhos com visualização ampliada, depoimentos de clientes, localização com mapa e horários de funcionamento, além de contato via WhatsApp e Instagram. Layout 100% responsivo, com menu mobile, animações suaves de rolagem e número de WhatsApp centralizado em um único arquivo de configuração para facilitar a personalização por cliente.

  • Agendamento via WhatsApp com mensagem pronta por serviço
  • Catálogo de serviços com preços e destaque para o mais pedido
  • Galeria com lightbox e selo de "aberto agora" conforme o horário
  • Mapa, horários de funcionamento e contato em layout mobile-first
