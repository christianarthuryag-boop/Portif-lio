## Projeto principal: Lunari

Uma plataforma de leitura de novels, mangás e manhwas, desenvolvida continuamente para unir leitura e comunidade.

O código local inclui catálogo, leitores de texto e imagens, biblioteca, perfis, comentários e administração. Os desafios envolvem organizar formatos de leitura, integrar frontend e API e respeitar permissões de acesso.

**Tecnologias verificadas no desenvolvimento:** HTML, CSS, JavaScript, Node.js, Express e SQLite. A disponibilidade atual dos recursos no site público não foi reconfirmada. A versão 4.0 está local e ainda não foi publicada; SQLite não foi confirmado em produção. Código-fonte privado.
